## 2026-11-03 指法手部重做（edclub 风格）

- 参考对象 www.edclub.com 的实现：一张 716×380 的 hand-both.svg 内含 58 个手型层（每层 6~9 条 path），
  全部 `.st0{display:none}`，按键时只把目标层 `display:block`；填充仅 `#E0E1E2` + opacity .33，
  描边 `#808285` 2px，高亮用 `.st5` 蓝色描边；整体再加 `opacity .8`。本质是**淡线稿**，不是实心手。
  美术资产有版权，只复刻机制。
- 本站实现（assets/style.css + index.html 内联 SVG）：左手 148×182 viewBox、单段胶囊手指（4 根，各自
  `rotate` 成扇形），拇指并入手掌轮廓 path（避免拼接缝），另有一条 `.thumb-hl` 轮廓做拇指高亮。
- 按压动画：`.finger.is-down { transform: scaleY(.84) }`（`transform-box:fill-box; transform-origin:50% 100%`），
  只缩短不下移——加 translateY 会在 f-base/f-tip 之间露缝，所以手指做成单段。
- 联动：app.js 用 `heldKeys` 集合 → `syncHands()` 统一推导两手状态，取代原来的 `setFingerActive`；
  这样 shift+n 之类多键同时按不会互相覆盖；只有非拇指手指按下才加 `.is-pressing`（其余手指褪色 + 整手微沉）。
- 布局：`.keyboard-panel` 列宽 86→120px，gap 24→16px，手 svg 120×148。
- 配色变量：`--hand-fill / --hand-fill-op / --hand-line`，深色主题 op 仅 0.055（白）。
- 验证方式：起 `python -m http.server 8899` + Edge `--remote-debugging-port` + node 内置 WebSocket 走 CDP，
  派发 keydown/keyup 走真实事件链路，再用 Page.captureScreenshot 取图。

## 2026-11-03（晚）手部改为「预画姿势图层」，替换掉计算式变形

上一版的 `scaleY(.84)` 单层手指只是把手指压短，整只手不朝目标键移动，看着像贴图在动。
这次按 edclub 的机制重做：**每个键一张静态姿势图，运行时只切换显示**。美术全部自己画，没用对方素材。

生成器 `_data/build-hands.js` → 产物 `assets/hands.js`（`window.HAND_LAYERS.left/right`，63 层 / 约 100 KB）：
- 每层是一整只手：外层 `<g transform="translate(dx dy) rotate(r 82 190)">`，`dx=列差*1.35`、`dy=行差*1.15`、`r=clamp(列差*1.5, ±5.5)`。
- 目标手指从指根伸到键位方向：`tip += (列差*3.6, 行差*7.4)`，并加 `bow` 让指节带弧度；其余手指跟着走 0.7/0.9，才像同一只手在动。
- 目标手指包 `<g class="tgt">`，CSS 里换 `--accent` 描边 1.9 + 填充 .2；其余手指不动。
- ID 命名用键盘 code（`KeyQ`/`Space`/`ShiftLeft`…），`neutral` 是放松姿势，找不到就用它兜底。

几何要点（左手 viewBox 0 0 160 210，右手靠 CSS `scaleX(-1)` 镜像，所以右手层的方向系数取反）：
- 四指：pinky x41 w7.4 tip62 / ring 59.5 8.6 46 / middle 78 8.9 36 / index 96.5 8.6 48；指尖收窄到 0.84。
- 指根不写死：`palmEdgeY(x)+5`，让切口正好落在掌口下方。
- 掌口 `EDGE`（10 个点，指缝处下凹）用 `smoothing()`（过点二次曲线）连起来，比直线像手。
- **裁切**：手指放在 `<g clip-path="url(#hc-…)">` 里，裁切边界用**同一条 EDGE 同样的平滑**、只整体抬高 0.4。
  用折线近似会在掌面上露出一条色带（试过，很明显）；抬高 0.4 后切口藏在掌缘 1.35 描边下面。
- 拇指并进手掌轮廓（不做独立 path，避免接缝和双重半透明叠加）；按空格时把轮廓里那一段单独描蓝（`fill:none` + 2.1 描边）。
- 手腕画到 y=222（超出 viewBox），靠 svg 默认裁切切掉，底部才不会留一条横线；因此 CSS 里**不要**给 `.hand-svg` 加 `overflow: visible`。

运行时（app.js）：
- `heldStack` 记录按住顺序（最新在前）；`handLayerCode(side)` 取该手最近按下的键，没有就 `neutral`。
- `setHandLayer` 用两个 `.hand-frame` 轮换：新的写 innerHTML 后 `.on` 淡入，旧的移除 `.on`，130 ms 交叉淡化。
- `visualKey` 的抬起分支不再要求输入框聚焦，否则按着键切走焦点会让手卡在下压姿势。

验证坑：
- 无头截图会抓到 `.keyboard-dock` 的 `max-height` 过渡中间态（量到 `dockH=0 / op=0`），看起来像"键盘不见了"。
  测试页要在 iframe 里注入 `*{transition:none!important}` 再截图/测量。
- iframe 尺寸要写成 100vw/100vh，否则 window-size 变了但内部布局不变，矮屏测试会失真。

未做：线上站点还没同步这一版。

## 2026-11-03（夜）手部改为照搬 edclub 原始图层

用户要求直接照搬，不再自己画。做法：
- 素材：`assets/hand-both.svg`（716×380，58 个姿势图层，每层一整只手；`.st0` 隐藏 / `.st1` 填充 #E0E1E2 op.33 / `.st2` 描边 / `.st3` 指甲组 op.5 / `.st4` 指甲填充 #AEB0B2 / `.st5` 蓝色高亮 3px）。
- 拼接方式（与原站一致）：**一张 SVG 里同时显示左右各一个图层**，不是两只手各一张图。
  驱动函数 `focusHand(leftId, rightId)` 逐行照搬原站 `focus_hand`：遍历 `.st0`，
  id 命中 l 或 r 就 `display:block` 并记 shown，其余 `display:none`，最后没命中的手退回 `neutral-left/right`。
- 取层规则：某只手显示「该手最近按下的键」的图层，没有就 neutral。Shift 在左手 → 按 y 时左手 shift-left、右手 y，自动成立，不需要查 modifier 表。
- 构建：`_data/build-hands.js` 读 `assets/hand-both.svg` → 去 XML 头/<style>、id 加 `hb-` 前缀、压空白 → `assets/hands.js`（`window.HANDS_SVG`，271KB）。样式类改由 style.css 收口，避免 `.st0` 全局污染。
- 布局：键盘面板改成单列（kb-bar / kb-wrap），手 `position:absolute` 盖在 `.kb-board` 上，`width:100%`（这样横向与 15 列的键位天然对齐），`bottom:-106px`，`opacity .88` + 底部 mask 渐隐，面板 `overflow:hidden` 收边。
- 键高 25→34px（原来太扁，手会显得过大）。矮屏（max-height 800）手缩到 80% 居中、bottom -100。
- 验证脚本 `_data/re/shot.js`：起 8899 静态服务 + CDP 派发按键 + 裁剪截图；注意 `Runtime.evaluate` 的返回值在 `res.result.result.value`。

## 2026-11-03（深夜）「下一个字母」指法提示 + 手部与键位的对齐

需求：在要打某个字母之前，键盘上对应手指就压在那个键上、键高亮，提示该用哪根手指。

实现（`assets/app.js`）：
- `hintState()`：`当前已提交字数 → 该字拼音 → 去掉输入法缓冲里已敲的字母 → 剩下的第一位`。
  缓冲取自 `compositionupdate` 的 `e.data`；敲错/简拼时返回「这一位本该敲的字母」，把人带回来；
  拼音敲全返回 `done`（状态栏显示「选字 · 空格上屏」）。`hideAnswer` 开启时不提示（否则漏读音）。
- `updateHint()` 只在变化时动 DOM：给目标键加 `.is-hint`，并 `syncHands()`。
- `layerOfHand()` 增加兜底：没有真实按键时，用提示字母的图层，其它手退回 neutral。
- `renderAnswer()` 末尾调用 `updateHint()`，并在拼音行给待敲字母加 `.nx`（跟随呼吸）；
  `nx` 限制在当前字内（`nxLimit = pre[typed+1]`），避免拼音敲全时跳到下一个字。

样式：`.kb-key.is-hint` 靛青描边 + 呼吸光晕（`@keyframes kbHint`）；`.answer .py i.nx` 同步呼吸。

手部对齐（关键）：原站 `this.$hands.css({height:363, top:-10, left:0, transform:"translateX(55px) scale(1.55)"})`，
键盘容器宽 685。照搬 1.55 后指尖仍偏左偏上，最终按实测拟合：
`.hands { bottom:-128px; transform: translateX(6.7%) scale(1.587); transform-origin:50% 50% }`，
26 个字母键的指尖误差 ≤10px（`.st5` 描边最上点当指尖，用「SVG 用户坐标 → 布局盒 → CSS transform」手算，
`getScreenCTM()` 在缩放容器里给的坐标不可信）。矮屏（max-height:800）改为 `.kb-wrap{width:72%}` 整体等比缩小 + 键高 25px。

验证脚本：`_data/re/hint.js`（CDP 真按键 + `Input.imeSetComposition` 模拟拼音，可 `ANS=字` 固定词、`RED=1` 染红高亮手指做像素测量）、
`_data/re/precise.js`（指尖 vs 键中心偏差表）。
