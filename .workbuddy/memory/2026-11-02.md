# 2026-11-02

## 项目立项：背单词 + 中文打字练习网页

用户想做一个类似「不背单词」的网页：导入词书 → 制定计划 → 每天弹单词卡 →
看到英文回忆 → 按键揭示中文 → 再把中文意思用键盘打出来。目标是背单词和练打字合一。

### 已锁定的产品决策（经 12 轮提问确认）

| 决策点 | 定论 |
|---|---|
| 词书导入 | Excel/CSV 四列模板（单词/音标/词性/释义）；首版先用内置样例词 |
| 存储 | 纯本地 IndexedDB + localStorage，不登录、无后端 |
| 规模 | 几百词一本书，每天 30-50 词 |
| 设备 | 电脑键盘优先，不做手机版 |
| 核心循环 | 出现单词+音标+自动发音 → 空格/点击揭示中文 → J/K/L 三档自评 → 输入框自动聚焦打字 → 判定 → 下一词 |
| 自评档位 | 忘了 / 模糊 / 很熟（三档） |
| 判定规则 | 只比汉字，词性标注和标点不算；一字错即错 |
| 打错处理 | 原地重打，打对才走；连错 3 次自动给答案放行 |
| 复习算法 | 间隔重复（简化 SM-2），自评驱动，错词与到期词自动回流 |
| 视觉 | 极简打字风（Monkeytype 那种），浅色为主可切深色 |
| 附加功能 | 速度与准确率曲线、打字音效、设置项；不做独立错词本、不做打卡连续天数 |

### 关键技术结论

- **中文判定的坑**：不能在 keydown 里逐键比对。必须用 `compositionstart/end` 状态机，
  在组词结束后或 Enter 提交时判定；Chrome/Safari 在 compositionend 后会补发 input，需去重。
  比对用字符级 LCS diff，输出「对/错/漏」三态高亮。
- **快捷键与输入法冲突**：自评不能用 1/2/3（拼音选字键），改用 J/K/L。
  空格作揭示键只在输入框未聚焦时有效，一旦聚焦必须交还给输入法。
  需要严格状态机：回忆 → 已揭示 → 打字中 → 已判定。
- **发音**：有道公开音频接口 `dict.youdao.com/dictvoice?audio=WORD&type=2`，真人音、无需 key；
  `SpeechSynthesis` 兜底。自动播放需预加载下一个词的音频避免延迟。
- **存储量级**：几百词用 IndexedDB 完全够，不必上后端。

### 工具选型

- 必需 skill：`sites`（发布为应用）、`workbuddy-sheet-generation`（生成词书导入模板 xlsx）
- 不需要 `cloud-service`（纯本地，省掉整个后端）
- 插件/连接器：核心功能一个都不需要，发音和解析都能前端解决

产品决策（用户明确要求）：

取词调度（重写，替代原来的 buildQueue/buildExtra）：
- `pickNext()` 优先级：本轮重来 `state.retry` → 到期复习 `duePool()` → 顺着书序的 `nextNew()`（首个 seen=0 的词）。
  没有 cursor 变量：新词位置由「第一个没学过的词」反推，导入自定义词表也不会错位。
- `dueAt` 改为**时间戳**（旧数据在 `load()` 里把 `due:'YYYY-MM-DD'` 迁移成时间戳，`interval`→`iv`）。
- 忘了 → `dueAt=now+2min`，并在本次学习里插到 **4~6 个词之后**；
  模糊 → `dueAt=now+8min`，插到 **11~14 个词之后**；
  很熟 → 1 天 / 3 天 / ×ease 递增。
- 本轮重来只存在内存（`state.retry`），跨会话靠 `dueAt` 兜底。
- 全书过完且无到期词 → `endAll()` 显示完成页，按钮「再复习 15 个」（`forceBatch` 取 dueAt 最早的 15 个）。

按键音重做（关键：不要拖沓）：
- 噪声 buffer 改成**平坦白噪**，包络全交给 gain：`linearRamp 1.5ms 起音 → exponentialRamp 到 0.0001`，
  down 21ms / up 12ms / space 25ms / enter 28ms。
- 参数表 `CLICK`：down f=3300 Q0.95 hp1300 amp0.62 body0.042 bf620；
  up f=4700 Q1.2 hp2200 amp0.30；space/enter 更低频 + 更大 body。
- 腔体改为 sine 且只做前 70% 的短促起音（原来 triangle 38ms 拖尾是「闷/拖沓」的来源）。
- 键盘 `keydown` 加 `if (e.repeat) return`，长按不再连发咔声。

验证手段（可复用）：
- `_test/audio.html`：把 `window.AudioContext` 换成 `OfflineAudioContext`，`startRendering()` 后
  算 1ms 窗 RMS 包络 + 12ms DFT 频谱。实测 down：peak 0.46、起音 1.3ms、有效 9~10ms、尾巴 11ms；
  频谱 400Hz(body)/4kHz/7k/9k 三个峰，符合「低频 thock + 高频脆响」。
- `_test/run.html` 驱动真实 DOM 跑 24 个词，打印取词顺序 + 记录，验证回流时机。
- `_test/resume.html` 先 seed localStorage 再动态插 iframe，验证「续学 + 到期复习优先」。

踩坑补充：
- 词库答案不能简单改成「第一个词性组的第一义项」：6687 词里 625 个会更差
  （establish→植物定植、stipulate→有托叶的）。已验证并回退，保持「各组首义项里最短的」规则。
- `.rate-row/.type-row` 用绝对定位叠在 `.action-zone` 里，截图若无头浏览器裁剪，
  会误判成输入框溢出；用 `document.documentElement.scrollWidth === clientWidth` 判断才可靠。
